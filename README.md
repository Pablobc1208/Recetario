# Recetario

Aplicación web de recetas desarrollada como proyecto de clase (HTML, CSS, JavaScript, PHP y SQL).

## Estructura

- `CSS/`: hojas de estilo
- `JS/`: scripts del cliente
- `PHP/`: lógica del servidor
- `docs/`: documentación del proyecto
